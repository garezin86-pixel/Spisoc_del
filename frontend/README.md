# Frontend для Spisok Del

React-приложение (Vite) для работы с API backend-а. Общее описание проекта, запуск backend-а и тестов — в [корневом README](../README.md); что изменилось в редизайне — в [docs/redesign.md](../docs/redesign.md).

## Запуск

```bash
cd frontend
npm install
npm run dev      # http://localhost:5173
npm run build    # проверка production-сборки
```

Backend должен работать на `http://localhost:8000` (`python run.py`). Если он на другом адресе, создайте `frontend/.env.local`:

```env
VITE_API_BASE=http://localhost:8000
```

## Как устроен интерфейс

| Что | Где |
|---|---|
| Состояние, загрузка данных, переключение страниц | `src/App.jsx` (значение состояния `tab` выбирает страницу) |
| Структура меню: группы, страницы, значки, счётчики | `src/constants/navigation.js` (`NAV_GROUPS`, `FOOTER_ITEMS`) |
| Боковое меню, верхняя панель, мобильное меню | `src/components/layout/` |
| Страницы и крупные блоки | `src/features/` |
| Переиспользуемые компоненты | `src/components/` |
| Дизайн-токены и темы | `src/styles.css` (`:root`, `[data-theme="light"]`) |
| Стили оболочки и страниц | `src/shell.css` |

### Как добавить страницу
1. Создайте компонент в `src/features/`.
2. Добавьте пункт `{ tab, label, icon }` в нужную группу `NAV_GROUPS` (или в `FOOTER_ITEMS`).
3. В `App.jsx` отрисуйте компонент при `tab === "<ваш tab>"`.

### Оформление страниц
Страницы строятся из одинаковых блоков (`shell.css`): корень `cl-page`, заголовок `cl-head` (`cl-title`, `cl-sub`, `cl-actions`), вкладки `cl-tabs`, строка фильтров `cl-filters`, карточки `card`, таблицы `tr-table`, сетка карточек `pj-grid`. Цвета берите из переменных (`var(--surface)`, `var(--text-muted)`, `var(--accent)` и т. д.), а не из жёстко заданных значений — иначе страница сломается в светлой теме. Новые CSS-переменные добавляйте сразу в оба блока тем.

### Брейкпоинты
`1200px` — правая колонка «Задач» уходит под список; `900px` — боковое меню становится выезжающим, таблицы превращаются в карточки; `700px` — компактные карточки, поля ввода 16 px (iOS не приближает страницу), увеличенные цели касания.
