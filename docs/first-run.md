# Первый запуск: компания и администратор

Скрипт спросит название компании, имя и пароль администратора и стадии воронки (или сгенерирует пароль и покажет его один раз):

```bash
python -m scripts.init_instance
# в Docker (после `docker compose up -d`, когда приложение применило миграции):
docker compose run --rm app python -m scripts.init_instance
```

Без диалога (скрипты, автоматизация) значения берутся из аргументов `--company`, `--admin`, `--stages` и переменных
`INIT_ADMIN_PASSWORD` (не короче 8 символов; не задан — будет сгенерирован). Повторный запуск безопасен: если в базе
уже есть пользователи, скрипт ничего не меняет. Сотрудников добавляйте из админ-панели ссылкой-приглашением;
самостоятельное создание компаний (`ALLOW_COMPANY_REGISTRATION`) на клиентской установке лучше оставить выключенным.

## Демо-данные

Чтобы увидеть систему «в деле», загрузите демо-данные: 12 клиентов (7 компаний и 5 частных лиц) со сделками, звонками и
встречами, задачами и ближайшими событиями. Администратору для этого есть кнопка «Загрузить демо-данные» на пустой
вкладке «Клиенты» или флаг при первом запуске:

```bash
python -m scripts.init_instance --demo        # либо INIT_DEMO=1
```

Демо-клиенты помечены «демо». Кнопка «Удалить демо» (над списком клиентов, только admin) убирает их вместе со сделками,
задачами и встречами, а ваши настоящие данные не затрагивает.
